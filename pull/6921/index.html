PR #6921: Standardize Literal Spacing Values to Design Tokens

Standardized component spacing to canonical design tokens across 4 component stylesheets. Replaced off-scale and hardcoded pixel/rem measurements in Date Picker, File Input, Language Selector, and Process List with official USWDS units() tokens, achieving zero visual delta while restoring design token encapsulation and maintaining accessible tap targets.

3. Language Selector: 0.3rem vs units(0.5) (0.25rem)

CodeRabbit finding: 0.8px difference (4.8px vs 4.0px). Both remain in rem.
DECISION: Keep units(0.5)
Because units(0.5) compiles to 0.25rem, it retains 100% root-relative zoom scaling while snapping cleanly onto the official 8px grid. The 0.8px subpixel difference is completely invisible to users and eliminates an ungrounded literal measurement.
